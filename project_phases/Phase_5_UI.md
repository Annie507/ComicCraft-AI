# Phase 5 – User Interface

## Objective

Create a simple and user-friendly interface for generating AI comics.

## Key Activities

* Design the ComicCraft-AI home page.
* Add a project title and short description.
* Create a form for entering the story idea.
* Add fields for character name and setting.
* Provide options for story tone and art style.
* Add a Generate Comic button to start the process.
* Use HTML and CSS to create a clean and responsive interface.

## Outcome

A simple web interface was developed to collect user inputs and start the AI comic generation process.
